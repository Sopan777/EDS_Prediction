ARCHITECTURE

Prediction Engine Core

DHATU BODH uses a two-tier hybrid architecture combining deterministic stoichiometric rule gating with non-parametric empirical component fingerprinting.

Tier 1: Material Family Classification Evaluates elemental concentration bands and stoichiometric ratio gates (Cr/Ni, Cu/Sn, W/Mo) without stochastic black-box distortion.
Tier 2: Component Statistical Matching Scores candidate components using standardized robust distance based on empirical medians and interquartile ranges (IQR).
